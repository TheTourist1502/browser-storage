🪣 Storage Buckets

navigator.storageBuckets — isolated, eviction-controlled storage units (Chrome 122+)

⚠️ Limited Support: Storage Buckets API is available in Chrome 122+ only. This page shows a live demo where supported, and a visual simulation otherwise.

Real-World Example: Video Editor App

A browser-based video editor uses separate buckets per project. The drafts bucket is eviction-friendly (cache-like), while the exports bucket is marked persistent so the OS never auto-deletes finished renders.

Why Buckets?

    

      
ProblemBucket Solution

      
        
One localStorage for everything → key collisionsEach bucket has isolated localStorage/IDB/Cache

        
Browser evicts all origin storage at oncePer-bucket eviction policy (relaxed vs strict)

        
No way to scope storage by featureNamed buckets per project, user, or feature

        
Can't set storage quota per featurequota option limits bucket size
