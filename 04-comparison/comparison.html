Decision Tree — Which Storage to Use?

Does the server need to read it?
Yes → Use a Cookie (HttpOnly + Secure if it's auth)
Should it survive closing the browser?
Yes → localStorage
No → sessionStorage
Should it be isolated per tab?
Yes → sessionStorage
No → localStorage
Is it an auth token?
Yes → HttpOnly Cookie set by server (never localStorage)
